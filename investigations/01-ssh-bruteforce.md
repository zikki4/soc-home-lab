# Разбор инцидента: SSH brute-force

**Резюме:** отбитая попытка SSH-брутфорса (T1110.001) с одного источника,
компрометации не выявлено. Приоритет средний.

| | |
|---|---|
| **Источник данных** | Wazuh SIEM (журналы sshd/PAM, агент на host ubuntu) |
| **Хост** | ubuntu (192.168.100.128) |
| **Период событий** | 21.09.2026, 18:09:20 – 18:11:26 |
| **Дата анализа** | 23.09.2026 |

## 1. Хронология

За период 18:09:20 – 18:11:26 зафиксировано 31 событие, соответствующих
~24 попыткам неудачного входа по SSH с IP 192.168.100.129 на host ubuntu
(192.168.100.128). Признаков успешного входа с данного IP не обнаружено.

## 2. Наблюдения

- Попытки идут с интервалом ~2 секунды, все с одного IP 192.168.100.129
- Вход под несуществующим пользователем (rule 5710) — перебор имён вслепую
- SIEM классифицировал активность: Brute Force: Password Guessing (T1110.001),
  Remote Services: SSH (T1021.004)
- **Вывод:** совокупность признаков (машинный ритм + единый источник +
  перебор имён) соответствует автоматизированному подбору учётных данных

## 3. Проверка / исход

- **Запрос:** `rule.groups: authentication_success and data.srcip: "192.168.100.129"`
  Результат: успешных входов с адреса атакующего не зафиксировано
- **Пивот:** `data.srcip: "192.168.100.129"` — вся активность IP это только
  неудачные попытки (rule 5710, 5503), других действий нет
- **Вывод:** атака цели не достигла, компрометация не подтверждается

## 4. Ограничения

Данные собраны с одного источника (Wazuh SIEM). Проверка охватывала только
попытки входа через SSH, один хост (ubuntu) и один адрес источника.
Модификация логов после возможного входа не проверялась.

## 5. Вывод

**Вердикт:** True Positive, приоритет средний. Подтверждённая попытка
брутфорса без успешной компрометации — фактического доступа атакующий не получил.

**Рекомендации:**
- заблокировать источник 192.168.100.129
- проверить другие хосты на попытки с этого IP
- отследить смену тактики (переход с несуществующих учёток на реальные)
- L1 обрабатывает самостоятельно; эскалация на L2 не требуется при отсутствии
  признаков компрометации
