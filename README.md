# soc-home-lab

Домашняя SOC-лаборатория для отработки навыков аналитика: развёртывание SIEM,
проведение атак и их обнаружение, разбор инцидентов.

## О себе

Отвечаю за IT-инфраструктуру на производственном предприятии:
администрирование сети и рабочих станций в офисе, поддержка внутренних систем.
К технике пришёл из практики и интереса — самостоятельно осваивал сетевое
администрирование, работу с веб-сайтом компании, писал внутренние инструменты
(система скидок на Go).

Сейчас целенаправленно развиваюсь в информационной безопасности, направление —
SOC-аналитик (L1). Эта лаборатория — то, где я отрабатываю реальные сценарии:
разворачиваю SIEM, провожу атаки и учусь их обнаруживать и расследовать.

## Стенд

- **SIEM:** Wazuh (сервер + агент)
- **Атакующая машина:** Kali Linux
- **Цель:** Ubuntu с установленным агентом Wazuh
- **Сеть:** изолированная host-only, гипервизор VMware Workstation

## Разборы инцидентов

## Отработанные навыки

- Развёртывание и настройка Wazuh SIEM (сервер, агенты, сбор событий)
- Анализ логов Linux: journald, auditd (execve, auid, дерево процессов)
- Анализ Windows Event Log: ключевые Event ID, Logon Types
- Захват и разбор сетевого трафика (tcpdump, BPF-фильтры)
- Расследование в SIEM: фильтрация потока событий, пивот по индикатору (DQL)
- MITRE ATT&CK: разбор атак по тактикам и техникам
- Анализ фишинга: заголовки писем, SPF/DKIM/DMARC
